# Techniques

This directory stores general process notes that apply across more than one
recipe.

Examples:

- pantry-led planning,
- low-gas cooking and appliance choice,
- blooming whole spices,
- balancing acid and umami,
- using canned fish well,
- building pulse and grain bowls,
- adapting fresh ingredients to weekly plans,
- distinguishing stock items from recipe-specific purchases.
