# Recipes

This directory stores working recipes, stable house recipes, weekly candidates,
and templates.

Suggested subfolders:

- `historical/` for historically anchored savoury recipes and practical
  reconstructions,
- `weekly-candidates/` for recipe ideas being considered for a coming week,
- `templates/` for reusable drafting formats,
- future cuisine or format folders as patterns emerge.

Working file:

- `ingest.md` is the temporary intake file for rough recipe notes, conversation
  dumps, and partial ideas that still need to be processed into their proper
  long-term locations.

Recommended practice:

- one file per recipe family,
- mark recipe status clearly,
- record stock ingredients separately from on-demand purchases,
- record equipment path, gas-use fit, active attention, and batch/portion
  assumptions,
- link to related cook logs and research notes,
- promote a recipe from trial to stable only after repeated success,
- after processing `ingest.md`, move useful content into the correct recipe,
  research, inventory, technique, plan, or shopping files and reset it for
  reuse.
