# Weekly Candidates

This directory stores recipe ideas that are being considered for a specific
week but are not yet stable house recipes.

Use these notes when a recipe sounds promising but still needs:

- perishables listed,
- specialty purchases assessed,
- timing checked,
- serving/batch size decided,
- adaptation notes written,
- or a first cook log.

Once cooked and assessed, move or rewrite the candidate into the proper recipe
location and link the cook log.
