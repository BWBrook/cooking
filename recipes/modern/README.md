# Modern Recipes

This directory stores contemporary pantry, convenience, supermarket, and
everyday house recipes.

Use this lane for recipes where the appeal is practical usefulness rather than
historical reconstruction. These can still be pantry-aware, carefully adapted,
and worth logging after cooking.

Each recipe should make clear:

- source basis, if adapted from a packet, label, video, book, or conversation,
- stock ingredients versus on-demand purchases,
- equipment path,
- batch and portion assumptions,
- and what should be checked after the first cook.
