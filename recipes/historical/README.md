# Historical Recipes

This directory stores historically anchored savoury recipes and practical
modern reconstructions.

Use this lane for dishes where the historical source, context, or foodway is a
major part of the appeal. Each recipe should separate:

- historical basis,
- modern adaptation choices,
- current pantry fit,
- equipment path,
- and cook-log evidence once tried.

Recipes here can be trial recipes. They become trusted house recipes only after
actual cooking and judgement.
