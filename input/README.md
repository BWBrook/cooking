# Input

This directory stores raw intake and provenance files.

Current seed files:

- `kitchen_contents.txt`
  Initial ingredient list supplied by the user.
- `consolidated_notes.md`
  Follow-up ChatGPT conversation and consolidated pantry analysis.
- `equipment-preferences-interview.md`
  One-by-one interview covering equipment, storage, cooking habits,
  preferences, diet/nutrition, shopping, and workflow.

Useful content from these files has been promoted into `inventory/` and
`research/`, but the raw files are kept here as provenance.
