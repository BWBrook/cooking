# Cook Logs

This directory stores dated records of actual cooking sessions.

A cook log should capture:

- what recipe or plan was used,
- what changed from the written plan,
- what ingredients were actually used,
- what happened during cooking,
- how the final meal was judged,
- what should change next time.

Recommended filename style:

- `YYYY-MM-DD-short-name.md`

Each log should reflect what actually happened, not what was intended to
happen.
