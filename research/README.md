# Research

This directory stores concise research, orientation, and adaptation notes.

Use it for questions such as:

- which recipe traditions fit the current pantry,
- how to adapt a cuisine pattern to available stock,
- what a specialty ingredient would add,
- whether a candidate recipe deserves a weekly slot,
- how to use a pantry item more intelligently.

Each research note should include:

- the question or orientation topic,
- the date,
- the sources or provenance,
- a short synthesis in plain language,
- practical implications for this repository.

Web-sourced notes should include links. Internal orientation notes should link
to the relevant repo files or input files.
